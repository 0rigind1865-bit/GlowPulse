iOS Shortcut 快速分享

從 Threads 長按貼文 → 分享 → 選擇 「加入參考貼文」 Shortcut， 即可直接預填文字並開啟此頁面。

設定

需要 repo 權限。點此產生 →

iOS Shortcut 設定

在 iOS「捷徑」App 建立以下 Shortcut，之後從 Threads 長按任何貼文就能直接加到參考庫：

📋 捷徑名稱：加入參考貼文
1️⃣ 接收：文字（Share Sheet）
2️⃣ URL Encode：快捷指令輸入
3️⃣ 打開 URL：
（產生中…）
其中 TEXT 替換為步驟 2 的輸出
💡 開啟後瀏覽器自動切換到「參考貼文」頁並預填內容，確認後點「新增到參考庫」即完成。
